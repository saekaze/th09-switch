## Touhou 9 — 1.50a-r2 (first release)

A native Nintendo Switch port of Touhou 9: Phantasmagoria of Flower View v1.50a, built on YomotsuHisami's TH09 C++ reconstruction and compiled natively for ARM64.

* 🆚 The full game including **local 2P versus** — player 1 on the handheld / first controller, player 2 on a second controller.
* 🎮 **Remappable controls** through the in-game Key Config (defaults match the other ports; the D-Pad and sticks only move).
* 🔊 BGM streamed straight from `thbgm.dat` with the original loop points.
* 👆 Touch controls in handheld mode, Japanese text with MS Gothic or the Switch's own font.
* 📁 Recommended folder: `sd:/switch/touhou/touhou9/` — keep every Touhou port in one `sd:/switch/touhou/` folder instead of separate folders. The NRO's own folder is always checked first, and the old locations still work.

Put `touhou9.nro`, `th09.dat`, `thbgm.dat` and `msgothic.ttc` in the folder and launch from hbmenu.
